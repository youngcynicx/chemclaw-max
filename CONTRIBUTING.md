# Contributing

This project is an executable research prototype with safety and benchmark contracts.

## Good first contributions
- improve markdown documentation
- refine event schema
- create synthetic benchmark examples
- improve evaluation metric definitions
- propose cleaner repo structure
- add simple SQLite prototype code
- add reviewed Task A/B challenge cases
- improve a benchmark category without weakening its gold behavior

## Contribution principles
- keep outputs traceable
- avoid overclaiming
- prefer realistic lab workflows
- keep the small-lab setting in scope
- preserve event-first design
- keep Task A read-only and Task B writes policy-governed
- run `pytest -q` and the 25-case gold benchmark before submitting changes
- do not change expected outputs merely to match a current implementation limitation
