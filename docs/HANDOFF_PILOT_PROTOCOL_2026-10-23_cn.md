# 外部 AI 交接首轮实验协议

日期：2026-10-23。本文在本轮模型运行结果产生前制定；结果另见实测报告。

## 目标与范围

以一个明确标注为模拟资料的双样品、三阶段案例，连通“原始文本记录 → LLM 整理 → 共享样品状态 → 独立 AI 读取 → 追加与纠错 → 更新判断”。本轮为 text-only 开发先导实验，不运行 OCR。业务主库与人的界面沿用现状。

首要交付是可重复运行的工具、实际调用轨迹、状态快照和第一张对照结果表；根据实际错误再安排产品修复。

## 三种配置

1. direct：当前配置的同一模型读取各阶段全部已到达的原始记录，无 ChemClaw 知识工具，直接回答相同问题。
2. single：一个模型 Agent 直接使用共享状态及工具，无委派。仅在隔离实验库中将三角色可达能力的并集赋予根角色；使用直接整理工作的提示。保留实际配置用于复核。
3. multi：当前产品的 orchestrator、b_capture、b_query 三角色，根据任务自主委派。模型、输入资料、根任务时限与工具总预算口径与 single 一致，记录实际用量。

三个阶段分别回答两项任务，共六项。任务分别涉及初始经历/计划、追加结果/比较、纠错后当前值/后续安排。每种配置首轮只运行一次，不筛选最佳结果。初次失败保留；必要重试单独标为修复后运行。

single 与 multi 的提示及权限路由差异必须在结果中说明。direct 负责回答任务，不要求其产生数据库；持久状态质量单独比较 single/multi，不能把 direct 没有数据库当成回答错误。

## 独立强 AI

另启无本会话历史的独立 Agent。只提供研究目标、允许读取的工具说明、项目标识和运行器命令。它不读取原始 fixture 文件、参考答案、开发交接或本协议；原件需要通过 ChemClaw 的精确来源工具取得。

先在初始状态完成任务，再在追加/纠错后继续，观察其是否读取新状态并修订判断。独立 Agent 的表现与同模型三配置对照分别报告，不把不同模型能力差异解释成架构收益。

## 观测与评分

- 回答：样品归属、数值与单位、处理阶段、计划/完成、未知项、引用支持、比较及下一步建议。
- 持久状态：样品身份、共同事件、分段条件、实际测量、数值纠错历史、完成状态及重复记录。
- 交接：实际自主工具调用、关键来源追查、更新后的事实、两端消费同一对象的证据。
- 成本：墙钟时间、模型调用/工具调用/委派数、可取得的 token 用量；未知用量留空。

参考核对点在独立的评估文件中，禁止作为模型输入。人工逐项裁定以原始记录与真实回执为依据，记录答案或状态证据位置。先导结果不做显著性检验，后续以留出体系及重复运行扩展。

## 产物

原文与六项任务、实验专用运行脚本、外部 AI 运行器、各条件输出与状态、独立 AI 工具轨迹、评分与中文实测报告。私有凭据配置只供本机运行，不进入分享材料。
