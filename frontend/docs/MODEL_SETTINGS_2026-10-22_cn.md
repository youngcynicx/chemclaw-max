# 模型接口与研究交付升级（2026-10-22）

在“连接与设置 → 修改模型配置”中使用新版配置页。本说明覆盖旧 README 中关于模型和待审核提案的早期描述。

## 配置模型

主模型可使用 Chat Completions 或 Responses 协议，填写服务 Base URL 和准确的模型 ID。完整的 `/chat/completions` 或 `/responses` 地址会规范化为接口前缀；协议与地址不一致时直接报错。

“快速切换”提供 GLM、兼容 Chat、Responses、本机服务模板，以及可命名的本机方案。方案只保存地址、模型、协议、思考选项和预算，不包含密钥。填入方案不会立即切换；测试成功后才启用。更换远程端点需要重新填写密钥；同端点留空可复用当前内存中的密钥。本机免认证服务可显式选择不使用已有密钥。

视觉模型可配置独立的地址、模型和密钥，目前使用 Chat Completions。地址为空时使用主端点；模型为空时使用主模型，需要它支持图片。不同视觉端点不会自动获得主模型密钥。已填写视觉模型或地址时，启用测试同时检查主模型和视觉请求；视觉测试使用独立的 1024 输出预算。测试失败保留当前有效配置和表单输入。

## 思考参数

| 设置 | 行为 |
|---|---|
| 自动强度 | 未知模型保留服务默认；原生 GLM-5.3 保持 low |
| 原生 GLM-5.3 | low/high/max；保持 thinking enabled，不接受关闭或 medium 等不支持值 |
| OpenAI 格式 | Chat 使用 reasoning_effort；Responses 使用 reasoning.effort |
| OpenRouter 格式 | 使用 reasoning.effort |
| ZAI / DeepSeek 格式 | 使用 thinking 开关及所选 reasoning_effort；具体服务仍需支持对应强度 |
| Qwen 开关格式 | 支持保持默认或关闭，不将分级强度伪装为有效 |
| 不发送思考参数 | 配合自动强度，移除这些参数，使用服务行为 |

配置页显示当前实际适配的强度和格式。显式设置不会在宿主中静默降级；供应商是否支持该设置由连接测试和实际任务回执确认。输出预算与上下文窗口可编辑，范围分别为 256–131072 和 4096–2000000，另保留至少 2048 输入空间。窗口声明不会改变服务本身的真实上限。

当前原生联网验证为已配置的 GLM 对话与视觉服务；其他适配格式以隔离 HTTP/SDK 传输测试验证，不声称已实测每个供应商。其他原生协议的服务可经受支持的兼容网关接入。

## 研究交付

主 Agent 根据用户目标决定整理或查询。整理任务交给具备知识写入能力的角色，先查已有样品，写入默认采纳的知识，再读回实际事件和样品。纯查询保留只读。角色新增的是项目范围内的样品和提案读取能力；主 Agent 没有获得知识写入或人工审批权限。

界面的“知识已写入并读回”“已读取已有知识”“本轮没有知识写入回执”来自真实工具回执，和聊天完成状态分开显示。读回表示系统读取了对应版本，不表示人工签字或化学结论已验证。已关联某页不代表该页所有事实都已整理完整。

通用提示要求核对样品归属、分段操作、计划/完成、作废/更正值及事实/解释/推断/未知；语义判断继续由 LLM 负责。视觉提示要求保留删除线与边注归属，不增加化学答案分支。

答复支持转义后的 Markdown 标题、表格、代码块、删除线和安全链接，支持展开阅读与复制原文；宽表可横向滚动，原生 HTML 和图片标签不作为可执行内容插入。
