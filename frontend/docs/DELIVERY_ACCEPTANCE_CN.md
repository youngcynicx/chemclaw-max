## 设计与范围

统一六个入口：研究总览、知识与样品、证据工作区、库存与物料、Agent 协作、仪器与预约。纸白背景、深墨绿导航和少量浅绿强调，搭配本地字体、细网格、可操作的关系图及轻量动效。获奖作品用于研究完成度与交互原则，具体官方来源见 [设计参考](DESIGN_REFERENCES_CN.md)，不表示本作品已经获得评奖或认证。

前端采用无需构建的 ES modules 与 CSS，配套标准库 Python 本地读取桥。线上预览只包含合成数据；本地服务可连接同机 Core。
