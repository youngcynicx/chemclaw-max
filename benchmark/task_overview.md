# Benchmark Task Overview

## Task A - Inventory QA

Read-only questions over chemical state:

- amount
- location
- availability
- low-stock status/list
- sufficiency with unit conversion
- clarification for missing, unknown, or ambiguous items

## Task B - Inventory Update

Parsing and executing informal stock-changing reports:

- structured event fields
- deterministic policy decision
- guarded write or confirmation hold
- final inventory state
- duplicate-delivery behavior
- complete message/event/audit/transaction trace
